# 🎓 Multi-Agent Study Architect

Progetto di Agentic AI basato su **LangGraph** per la creazione di piani di studio strutturati. Implementa i principi di orchestrazione, gestione dello stato e qualità descritti nel tutorial "Agentic AI: Arch to Ops".

## 🛠️ Setup Ambiente

### 1. Inizializzazione e Installazione
```bash
# Inizializza l'ambiente virtuale
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Installazione dipendenze
pip install -r requirements.txt
```
