# Multi-Agent Study Architect

**Course:** Symbolic and Evolutionary Artificial Intelligence (SEAI)
**Program:** Master in Artificial Intelligence and Data Engineering (AIDE)
**Institution:** University of Pisa

This project leverages **LangGraph** to build an Agentic AI system that creates structured study plans and sources real-world educational materials. It implements advanced orchestration patterns including Human-in-the-Loop validation and Tool Use.

## Project Overview

The goal of this tool is to separate reasoning (planning) from action (research) to prevent common LLM pitfalls like hallucination. By treating the study plan as a dynamic state object, the system allows for iterative refinement and human oversight.

### Key Features
* **Agentic Orchestration:** Uses a graph-based state machine to manage the workflow between specialized agents.
* **Human-in-the-Loop:** Pauses the execution to allow the user to review the proposed syllabus. The user can request specific changes (e.g., "Add a module on Ethics") before the agent proceeds.
* **Real-World Grounding:** Integrates the **Tavily API** to fetch valid, accessible URLs for every module in the syllabus.
* **Self-Correction:** A dedicated "Judge" node evaluates the final output quality and triggers a retry loop if standards are not met.
* **Model:** Powered by **Llama-3 via Groq** for low-latency reasoning.

## Architecture

The workflow consists of four distinct nodes:

1.  **Planner Node:** Breaks down the user's topic into a structured 4-module syllabus.
2.  **Human Review Node:** Pauses execution to present the draft to the user. The user can approve it or provide feedback to request revisions.
3.  **Finder Node:** Iterates through the approved modules and performs live web searches using Tavily to find relevant study materials.
4.  **Judge Node:** Evaluates the final output to ensure resources were found and the plan meets quality standards.

## Setup and Installation

### 1. Prerequisites
* Python 3.10+
* A Groq API Key
* A Tavily API Key

### 2. Installation

Initialize the virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
```

Install dependencies:
```bash
pip install -r requirements.txt
```

### 3. Configuration
Create a `.env` file in the root directory and add your API keys:
```plaintext
GROQ_API_KEY=your_groq_api_key_here
TAVILY_API_KEY=your_tavily_api_key_here
```

## Usage
Run the main orchestration script:
```bash
python graph.py
```

1. Enter the topic you wish to study when prompted.
2. Review the proposed syllabus generated by the Planner.
3. Type your feedback to request changes, or press ENTER to approve.
4. The agent will search the web for resources and present the final study pack.
